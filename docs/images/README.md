# README figures

These SVGs are vector extracts from the accompanying
[paper](https://www.cs.toronto.edu/~kutyashev/assets/aamas_paper.pdf).

- `environment.svg`: Figure 1, PDF page 6.
- `scaling.svg`: Figure 2, PDF page 8.

The original figure content, including plot values, error bars, labels, and
legend, is preserved. Surrounding page text and original captions are omitted.
The SVGs add a white background and accessible titles and descriptions.
